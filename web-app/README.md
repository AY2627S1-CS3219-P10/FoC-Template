# Web App

Future responsive client for requester, courier, and administrator workflows.
The milestone mockups cover home, errand creation/review, open-errand browsing,
acceptance, and active-errand views across desktop and mobile sizes.

This folder is structure only. No frontend framework, routing, component,
styling, API client, or application behaviour is implemented.

## Intended internal layout

- `src/app/`: application shell, routing, and composition
- `src/components/`: reusable presentation components
- `src/features/`: workflow-oriented feature modules
- `src/services/`: future backend API adapters
- `src/styles/`: global design tokens and styles
- `tests/unit/` and `tests/e2e/`: client verification
